# ضماني (Damani)

تطبيق ويب تقدمي (PWA) عربي لحفظ الفواتير والضمانات والتنبيه قبل انتهائها.

## التشغيل
```bash
npm install
npm run dev      # تطوير: http://localhost:5173
npm test         # اختبارات منطق الضمان والتنبيهات
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # تجربة نسخة الإنتاج (Service Worker + العمل بدون نت)
```

للتجربة على الجوال: `npm run dev -- --host` وافتح عنوان جهازك من الجوال على نفس الشبكة.
الإشعارات والتثبيت تحتاج HTTPS (أو localhost).

## المرحلة 1 (الحالية)
إدخال يدوي، صور الفاتورة/بطاقة الضمان/المنتج، حساب المدة المتبقية ومدة الاسترجاع،
الشاشة الرئيسية مع البحث والفلترة، تفاصيل الضمان، الإعدادات (التنبيهات، الوضع الليلي، الهجري)،
وتنبيهات محلية (عند فتح التطبيق + Periodic Background Sync على أندرويد).
