# ضماني (Damani)

تطبيق ويب تقدمي (PWA) عربي لحفظ الفواتير والضمانات والتنبيه قبل انتهائها.

## التشغيل
```bash
npm install
npm run dev      # تطوير: http://localhost:5173
npm test         # اختبارات منطق الضمان والتنبيهات
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # تجربة نسخة الإنتاج (Service Worker + العمل بدون نت)
```

للتجربة على الجوال: `npm run dev -- --host` وافتح عنوان جهازك من الجوال على نفس الشبكة.
الإشعارات والتثبيت تحتاج HTTPS (أو localhost).

## المرحلة 1 (الحالية)
إدخال يدوي، صور الفاتورة/بطاقة الضمان/المنتج، حساب المدة المتبقية ومدة الاسترجاع،
الشاشة الرئيسية مع البحث والفلترة، تفاصيل الضمان، الإعدادات (التنبيهات، الوضع الليلي، الهجري)،
وتنبيهات محلية (عند فتح التطبيق + Periodic Background Sync على أندرويد).

## المرحلة 2
- **مسح QR الفاتورة الإلكترونية:** فك صيغة TLV/Base64 حسب مواصفات هيئة الزكاة والضريبة والجمارك
  (`src/lib/zatca.js`) واستخراج اسم المتجر، الرقم الضريبي، التاريخ والوقت (بتوقيت السعودية)، الإجمالي، والضريبة.
- **مسح باركود المنتج:** EAN/UPC/Code128 وغيرها، مع محاولة جلب اسم المنتج من Open Products Facts و Open Food Facts.
- **تصوير الفاتورة (OCR):** Tesseract.js بالعربي والإنجليزي، ويقرأ QR من نفس الصورة لو موجود (بياناته تغلب على OCR).
  أول استخدام يحتاج إنترنت لتحميل ملفات اللغة، وبعدها يشتغل بدون نت.
- في كل الطرق تنحفظ صورة الفاتورة/المنتج، وتنفتح شاشة مراجعة فيها الحقول المعبّأة معلّمة بـ"تلقائي".

الكاميرا تحتاج HTTPS (أو localhost). لو ما فيه كاميرا أو الإذن مرفوض، فيه زر "اختر صورة من جهازك".
